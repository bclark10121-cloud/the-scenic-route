# The Scenic Route v0.6.0

A new start screen, the same layout in every game on The Game Shelf (standard G5.21). Nothing else in the game changed.

## Five minute test

1. Install the APK over v0.5.5. Your saves stay.
2. Open the game. The start screen is a painted scene: a winding mountain road at golden hour, the low sun behind the hills and your red car parked at a lookout. It moves gently.
3. The title glows softly. Under it: one line of controls for what you used last, then Continue (drives on in the slot), Play (the slot list) and Settings. Version 0.6.0 sits at the bottom.
4. Press Play. Play opens the slot list. The slot you pick starts driving at once.
5. Press B or Back to return to the start screen. Up and down on the D-pad move between the buttons and wrap round.

## New in this version

- The shared start screen from kit 1.10.0 with this game's own painted scene, drawn in code.
- Buttons stacked in one column: gold for the first, dark glass for the rest, one focus ring. Continue shows only when there is something to continue.
- Music credits, tips and long key lists left the start screen. They live in Settings, About and How to play.
- Play opens the slot list. The slot you pick starts driving at once.

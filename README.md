# The Scenic Route

A calm rally drive through lakes, hills, snow, desert, woods and coast. No opponents and no damage. For Android and the browser.

Play in the browser or download the Android APK from the game page: https://bclark10121-cloud.github.io/the-scenic-route/

More games: https://bclark10121-cloud.github.io/

## What is in this repo

- `docs/`: the game page, the browser build, the Android APKs, the privacy page and the release notes.
- `BACKLOG.md`: what is done and what is planned.
- `CREDITS.md`: outside assets and their licences.

The game's source is kept in a private repo. Older versions and their APKs are on the Releases page.
